# নদী — সোনালি বিকেলে বাংলার এক নদী

রিয়েল-টাইম 3D দৃশ্য: বাংলার এক নদী দিয়ে মাঝির ডিঙি ভেসে চলে। দুই পাড়ে গ্রাম, নারকেল-সুপারি গাছ, ধানক্ষেত, চরে কাশবন। দিন থেকে রাত পর্যন্ত পুরো চক্র চলে।
কোনো ছবি, মডেল বা শব্দের ফাইল নেই। পাড়, গাছ, ঘর, নৌকা, টেক্সচার আর শব্দ সব লোড হওয়ার সময় কোড দিয়ে তৈরি হয়।

## চালানো

এই ফোল্ডারে:

```bash
npm run dev        # http://localhost:5173
npm run build      # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
npm run typecheck
```

এই ফোল্ডারের প্যাকেজগুলো (three, vite, typescript) মূল রিপোর `node_modules` থেকে নেওয়া হয়। আলাদাভাবে চালাতে চাইলে এখানে `npm install` করুন।

ডিবাগের জন্য `?debug` দিয়ে খুললে `window.__river` পাওয়া যায়। dev server চালু রেখে `node scripts/headless/shoot.mjs shots` চালালে headless Chrome দিয়ে দৃশ্যের ছবি তোলা যায়। কীভাবে ব্যবহার করবেন আর এই প্রজেক্টের পুরো ইতিহাস `HANDOFF.md`-এ লেখা আছে।

## নিয়ন্ত্রণ

নিচের বারে সব নিয়ন্ত্রণ আছে: সময় চালু/থামানো আর গতি, ২৪ ঘণ্টার টাইমলাইন (তাতে সেদিনের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের চিহ্ন; চিহ্নে চাপলে সেই মুহূর্তে গিয়ে ক্যামেরা সেদিকে ঘোরে), ক্যামেরা মোড, দৃশ্য, চাঁদের কলা, শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো আর সাহায্য। মাউস থেমে থাকলে বারটা সরে যায়, নড়লে ফিরে আসে। `?` চাপলে পুরো তালিকা দেখা যায়।

| কী | কাজ |
|---|---|
| টেনে আনা / তীর-চাবি | নৌকার চারপাশে ঘোরা |
| স্ক্রল / পিঞ্চ, `+` `-` | কাছে-দূরে |
| `V`, `R` | পরের দৃশ্য (পেছন, মাঝির পাশ, সামনে, উঁচু), শুরুর দৃশ্যে ফেরা |
| `1` `2` `3` | নৌকার ক্যামেরা, মুক্ত ক্যামেরা, চলচ্চিত্র |
| মুক্ত ক্যামেরায় `W` `A` `S` `D`, `↑` `↓`, `E` `Q`, `Shift` | চলা, ওপরে-নিচে, দ্রুত; টেনে বা `←` `→` দিয়ে ঘোরা |
| `C` | চলচ্চিত্র ট্যুর (লেটারবক্স, ক্যাপশন, কাট) |
| `Space`, `[` `]` | সময় চালু/থামানো, সময়ের গতি (১×, ৪×, ১৬×, ৬৪×) |
| `T` চেপে ধরা | সময় খুব দ্রুত |
| `N` | পরের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় বা চন্দ্রাস্ত |
| `M`, `F`, `H`, `?` | শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো, সাহায্য |

ঘড়ি প্রতিটা সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের কাছে ধীর হয়। চাঁদ প্রতিদিন একটু দেরিতে ওঠে আর তার কলা বদলায়। ১২ সেকেন্ড কিছু না ছুঁলে ক্যামেরা নিজে থেকে সেই ঘটনার দিকে ঘোরে, আর আরও পরে চলচ্চিত্র ট্যুর শুরু হয়। টানলে বা স্ক্রল করলে ক্যামেরা আবার আপনার হাতে ফিরে আসে।

## গঠন

| ফোল্ডার | কী আছে |
|---|---|
| `src/core/` | শেয়ার করা uniform (সময়, সূর্য, কুয়াশা, বাতাস), noise, seeded RNG |
| `src/render/` | পোস্ট পাইপলাইন (প্রতিফলন → HDR দৃশ্য → bloom → আলোর রশ্মি → grade), material patch, ক্যানভাসে আঁকা টেক্সচার, instancing |
| `src/world/` | ভূগোল (নদী, চর, গ্রাম), terrain, পানি, আকাশ, গাছপালা, গ্রাম, নৌকা, মাঝি, পাখি ও জোনাকি |
| `src/env/` | সূর্য আর চাঁদের অবস্থান ও কলা, ঘটনার কাছে ধীর হওয়া ঘড়ি, প্রতিটি সময়ের রং আর আলো |
| `src/rig/` | নৌকা অনুসরণকারী ক্যামেরা, মুক্ত ক্যামেরা আর চলচ্চিত্র ট্যুরের পরিচালক |
| `src/ui/` | লোডার, নিয়ন্ত্রণের বার, টাইমলাইন, সাহায্যের তালিকা, বাংলা সময় আর তিথি |
| `src/audio/` | Web Audio দিয়ে তৈরি শব্দ: নদী, বাতাস, দাঁড়, পাখি, ঝিঁঝিঁ |

চলচ্চিত্র ট্যুরের ধারণা (শট-তালিকা, কালোয় মিলিয়ে যাওয়া কাট, লেটারবক্স, ক্যাপশন) [koi-pond-garden](https://github.com/souranyp-stack/koi-pond-garden) (MIT) থেকে অনুপ্রাণিত। কোড নিজস্ব।
