# নদী — সোনালি বিকেলে মহেশখালীর পথে

রিয়েল-টাইম 3D দৃশ্য: মহেশখালী চ্যানেল দিয়ে মাঝি বৈঠা বেয়ে ডিঙি নিয়ে দক্ষিণে সাগরের দিকে চলে। জগৎটা আসল উপাত্ত থেকে গড়া মহেশখালী আর মাতারবাড়ী: মাটির উচ্চতা, উপকূল, পানির গভীরতা, জোয়ার, রাস্তা, জলপথ আর দালানের জায়গা মানচিত্রের ১:৩ মাপে (দূরত্ব তিন ভাগের এক ভাগ), আর উচ্চতা, দালান, নৌকা, জাহাজ সব আসল মাপে। ডান পাড়ে মহেশখালী দ্বীপ: বনে ঢাকা পাহাড়ের সারি, গোরকঘাটার দুটো জেটি আর বাজার, টিলার চূড়ায় আদিনাথ মন্দির আর তার সিঁড়ি, রাখাইন প্যাগোডা, পানের বরজ, পশ্চিমে ধানক্ষেত, লবণ মাঠ, কোহেলিয়া নদী, বঙ্গোপসাগরের সৈকতে ঢেউ ভাঙে, বালিতে লাল কাঁকড়া; দক্ষিণে সোনাদিয়া। উত্তরে মাতারবাড়ী: ২৭৫ m চিমনির কয়লা বিদ্যুৎকেন্দ্র, সঞ্চালন লাইন, আর ব্রেকওয়াটারে ঘেরা গভীর সমুদ্রবন্দর, যেখানে কন্টেইনার জাহাজ tug-এর সাহায্যে বার্থে ভেড়ে আর ছেড়ে যায়। বাম পাড়ে মূল ভূখণ্ড, বায়ুকল, মুখে কক্সবাজার। পথে নৌকা একটা পুরোনো ইটের সেতুর নিচ দিয়ে (তার ওপরে লাল ছাতা হাতে একটি মেয়ে) খাল ধরে শাপলা বিল পার হয়। পাড়ে আর নদীতে জেলেরা ভেসাল জাল তোলে-নামায়।
দৃশ্য খোলে সেদিনের সূর্যাস্তের একটু আগে, সোনালি আলোয়। দিন থেকে রাত পর্যন্ত পুরো চক্র চলে, আর আজকের তারিখ থেকে ছয় ঋতু: নদীর পানি ওঠে-নামে, মাঠের ফসল, গাছের রং আর ফুল, কুয়াশা, মেঘ, বৃষ্টি আর ঝড় ঋতুর সাথে বদলায়। একটাই বাতাস গাছ, ঘাস, ফসল, পানি, নৌকা, জাল আর কাপড় সব নাড়ায়। বাতাস যত জোরে, নদীর ঢেউ তত বড় আর লম্বা; নৌকা ঢেউয়ে ওঠে-নামে, দোলে, মাঝি শক্ত হয়ে দাঁড়ায়। নৌকা মাল নিয়ে পানিতে গভীরে বসে, চললে দুই পাশে পানি সরে, পেছনে wake; বৈঠার প্রতিটা টানে নৌকা এগিয়ে যায়, জোরালো টানে আরও। নদী দক্ষিণে সাগরের দিকে বয়, তাই সূর্য আর চাঁদ বামে ওঠে, ডানে অস্ত যায়, সামনে চোখে পড়ে না।
ধানক্ষেতে আসল ধান সারি করে দাঁড়ানো (চারা, সবুজ, পাকা সোনালি, নাড়া), শীতে হলুদ ফুলে ভরা সরিষা; উপকূলে লবণের খোলা: থিতানোর পুকুর, বাষ্পীভবন মাঠ, কালো পলিথিনে লবণ জমার মাঠ, মাটির আইল, স্তূপ আর গোলাঘর।
মাটি, নুড়ি আর গাছের বাকলের ১২টা ফটো-টেক্সচার (Poly Haven, CC0, ≈৪.৫ MB; নিচে তালিকা) ছাড়া কোনো ছবি, মডেল বা শব্দের ফাইল নেই। পাড়, গাছ, ঘাস, ঘর, নৌকা, কচুরিপানা, বাকি টেক্সচার আর শব্দ সব লোড হওয়ার সময় কোড দিয়ে তৈরি হয়।

## চালানো

এই ফোল্ডারে:

```bash
npm run dev        # http://localhost:5173
npm run build      # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
npm run typecheck
```

এই ফোল্ডারের প্যাকেজগুলো (three, vite, typescript) মূল রিপোর `node_modules` থেকে নেওয়া হয়। আলাদাভাবে চালাতে চাইলে এখানে `npm install` করুন।

ছবির মান: ধীর যন্ত্রে ছবি নিজে থেকেই একটু ছোট হয়ে মসৃণ থাকার চেষ্টা করে; সবচেয়ে ছোট ছবিতেও ৩০ fps-এর নিচে থাকলে কম খুঁটিনাটির স্তরে নামে (দূরের জিনিস কম, প্রতিফলন আর ছায়া কিছুটা মোটা, ঘন ঘাস কাছে)। `?quality=low` বা `?quality=high` দিয়ে খুললে স্তর বেঁধে দেওয়া যায়।

ডিবাগের জন্য `?debug` দিয়ে খুললে `window.__river` পাওয়া যায়। `?debug&geo` দিয়ে খুললে GIS যাচাইয়ের mode: ক্যামেরা আর কার্সরের lat/lon ও UTM, আঁকা মাটি বনাম উপাত্ত, জোয়ার, কাছের জায়গা; OpenStreetMap-এর রেখা, উপকূল আর দালানের ছাপ মাটির ওপরে; প্রতিটা জায়গায় পিন। `__river.goto(lat, lon, height)` দিয়ে যেকোনো আসল জায়গার ওপরে যাওয়া যায়। মানচিত্রের উপাত্ত `public/geo/`-এ, তৈরি হয় `scripts/geo/`-এর `fetch.mjs` আর `bake.mjs` দিয়ে; `node scripts/geo/check.mjs` আসল তথ্যের সাথে মিলিয়ে দেখে। dev server চালু রেখে `node scripts/headless/shoot.mjs shots` চালালে headless Chrome দিয়ে দৃশ্যের ছবি তোলা যায়। কীভাবে ব্যবহার করবেন আর এই প্রজেক্টের পুরো ইতিহাস `HANDOFF.md`-এ লেখা আছে।

## নিয়ন্ত্রণ

নিচের বারে সব নিয়ন্ত্রণ আছে: সময় চালু/থামানো আর গতি, ২৪ ঘণ্টার টাইমলাইন (তাতে সেদিনের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের চিহ্ন; চিহ্নে চাপলে সেই মুহূর্তে গিয়ে ক্যামেরা সেদিকে ঘোরে), বাংলা তারিখ, ঋতু আর জোয়ার-ভাটা, ক্যামেরা মোড (নৌকা, মুক্ত, হাঁটা, চলচ্চিত্র), দৃশ্য, চাঁদের কলা, ঋতু, আবহাওয়া, শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো, মানচিত্র আর সাহায্য। মাউস থেমে থাকলে বারটা সরে যায়, নড়লে ফিরে আসে। `?` চাপলে পুরো তালিকা দেখা যায়।

| কী | কাজ |
|---|---|
| টেনে আনা / তীর-চাবি | নৌকার চারপাশে ঘোরা |
| স্ক্রল / পিঞ্চ, `+` `-` | কাছে-দূরে |
| `V`, `R` | পরের দৃশ্য (পেছন, মাঝির পাশ, সামনে, উঁচু), শুরুর দৃশ্যে ফেরা |
| `1` `2` `3` | নৌকার ক্যামেরা, মুক্ত ক্যামেরা, চলচ্চিত্র (হাঁটার জন্য `G` বা বারের "হাঁটা") |
| মুক্ত ক্যামেরায় `W` `A` `S` `D`, `↑` `↓`, `E` `Q`, `Shift` | চলা, ওপরে-নিচে, দ্রুত; টেনে বা `←` `→` দিয়ে ঘোরা |
| `G` | নৌকা থেকে ঘাটে বা পাড়ে নামা, আবার নৌকায় ওঠা |
| হাঁটায় `W` `S`, `A` `D`, `Shift` | সামনে-পেছনে, ঘোরা, দৌড়; মাটি, জেটির পাটাতন, মন্দিরের সিঁড়ি আর সেতুতে হাঁটা যায়, হাঁটুজল পর্যন্ত পানিতে নামা যায় |
| `K` | হাল নিজের হাতে (`A` `D` দিক, `W` বাওয়া, `S` থামা); আবার চাপলে মাঝির হাতে |
| `L` | মানচিত্র: কোনো জায়গায় নৌকায় জলপথে (দূরের পথ কুয়াশা পেরিয়ে), হেঁটে বা ওপর থেকে যাওয়া |
| `C` | চলচ্চিত্র ট্যুর: ২৯টা দৃশ্যে এক বছর আর এক দিন (ভোর থেকে রাত, শীত থেকে শীত), নদী, খাল, পুরোনো সেতু, বিল, মাঠ, গ্রাম, জেলে, আদিনাথের সিঁড়ি আর পাহাড়, গোরকঘাটা জেটি, লবণ মাঠ, সোনাদিয়া, সৈকতের লাল কাঁকড়া, মাতারবাড়ী বন্দর আর বিদ্যুৎকেন্দ্র, ঝড়, বৃষ্টি, সূর্যাস্ত, চাঁদ ওঠা; dissolve, লেটারবক্স, ক্যাপশন |
| `Space`, `[` `]` | সময় চালু/থামানো, সময়ের গতি (১×, ৪×, ১৬×, ৬৪×) |
| `T` চেপে ধরা | সময় খুব দ্রুত |
| `N` | পরের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় বা চন্দ্রাস্ত |
| `Y` | পরের ঋতু (মেনু থেকে "আজকের তারিখ"-এ ফেরা যায়) |
| `B` | আবহাওয়া: ঋতু অনুযায়ী, পরিষ্কার, মৃদু হাওয়া, জোর হাওয়া, হালকা বৃষ্টি, বৃষ্টি, ঝড় |
| `M`, `F`, `H`, `?` | শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো, সাহায্য |

ঘড়ি প্রতিটা সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের কাছে ধীর হয়। চাঁদ প্রতিদিন একটু দেরিতে ওঠে আর তার কলা বদলায়। ১২ সেকেন্ড কিছু না ছুঁলে ক্যামেরা নিজে থেকে সেই ঘটনার দিকে ঘোরে, আর ৩০ সেকেন্ড কিছু না ছুঁলে চলচ্চিত্র ট্যুর শুরু হয়। টানলে বা স্ক্রল করলে ক্যামেরা আবার আপনার হাতে ফিরে আসে, আপনার সময় আর ঋতুসহ।

ঋতু, আবহাওয়া বা চাঁদের কলা বাছলে জগৎ হঠাৎ বদলায় না: বছর কয়েক সেকেন্ডে সেই ঋতুর দিকে ঘোরে (ফসল গজায়, পাকে, নদীর পানি ওঠে-নামে), চাঁদ ধীরে বাড়ে-কমে, বৃষ্টি আর বাতাস নিজের গতিতে আসে। প্রতিটা বাছাই এক মিনিট থাকে, তারপর জগৎ মসৃণভাবে আজকের ঋতু, ঋতুর আবহাওয়া আর আসল চাঁদে ফেরে।

## গঠন

| ফোল্ডার | কী আছে |
|---|---|
| `src/core/` | শেয়ার করা uniform (সময়, সূর্য, কুয়াশা, বাতাস, পানির উচ্চতা, ঋতু), noise, seeded RNG |
| `src/geo/` | মানচিত্রের উপাত্ত পড়া (মাটি, পানির ধরন, আচ্ছাদন, গাছের উচ্চতা, রেখা, দালান, জায়গা), lat/lon ↔ জগৎ আর UTM, জোয়ারের পূর্বাভাস |
| `src/render/` | পোস্ট পাইপলাইন (প্রতিফলন → HDR দৃশ্য → bloom → আলোর রশ্মি → grade), material patch (মাটির ফটো-স্তর, পানির নিচের রং), ক্যানভাসে আঁকা টেক্সচার, ফটো-টেক্সচার লোড, instancing |

## টেক্সচার

`public/textures/`-এ [Poly Haven](https://polyhaven.com)-এর ছয়টা টেক্সচার, প্রতিটার রং আর normal map (1K, WebP-তে রূপান্তরিত)। সবগুলো CC0, অর্থাৎ যেকোনো কাজে বিনা শর্তে ব্যবহার করা যায়।

| ফাইল | Poly Haven-এ | কোথায় |
|---|---|---|
| `grass_*` | forrest_ground_01 | পাড়ের ওপরের ঘাসজমি |
| `dirt_*` | brown_mud_dry | গ্রামের উঠান, শুকনো জায়গা |
| `mud_*` | brown_mud_03 | পাড়ের ঢাল, নদীর তলা |
| `sand_*` | sand_02 | চর |
| `pebbles_*` | ganges_river_pebbles | জলরেখার নুড়ি |
| `bark_*` | bark_willow | আম, রেইন ট্রি আর দূরের গাছের গুঁড়ি |

টেক্সচার না পাওয়া গেলে (যেমন অফলাইনে) দৃশ্য আগের আঁকা রঙেই চলে।
