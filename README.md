# নদী — সোনালি বিকেলে গ্রামের নদীতে

রিয়েল-টাইম 3D দৃশ্য: বাংলার এক গ্রামের ছোট নদী (≈৩০ m চওড়া) দিয়ে মাঝি বৈঠা বেয়ে ডিঙি নিয়ে ধীরে চলে। নদীর বাঁকে চরের কাশবন, পাড়ে পাড়ার বাড়িগুলো, মোহনায় খালে ঢুকে পুরোনো ইটের সেতুর নিচ দিয়ে (তার ওপরে লাল ছাতা হাতে একটি মেয়ে), খালের শাখার বাঁশের সাঁকো পেরিয়ে শাপলা বিলে গিয়ে পৌঁছায়। গ্রামটি কল্পনায় গড়া, কোনো আসল জায়গার মানচিত্র নয়: বাংলার নানা গ্রামের যা সুন্দর আর স্বাভাবিক, তা এক জায়গায় সাজানো, যাতে প্রতিটা জিনিসের নিজের যুক্তি থাকে (রাস্তা কোথাও না কোথাও যায়, সেতু দুই পাড় জোড়ে, বাড়ি ভিটার ওপরে, ফসল মাঠে)। ভিটার ওপর উঠান ঘিরে ঘর, বাড়ির চারপাশে বাঁশঝাড়, সুপারি, নারকেল আর আমগাছ, পুকুর আর ঘাট; উঁচু পথে ইট বিছানো গ্রামের রাস্তা, মাটির পায়ে চলা পথ; চারপাশে ধানক্ষেত, দিগন্তে দূরের গ্রামের গাছের সারি। জগতের কিনারার ওপাশে মাটি কুয়াশায় মিলিয়ে যায়।
দৃশ্য খোলে সেদিনের সূর্যাস্তের একটু আগে, সোনালি আলোয়, প্রথম পাড়ার পাশে নদীতে। দিন থেকে রাত পর্যন্ত পুরো চক্র চলে, আর আজকের তারিখ থেকে ছয় ঋতু: মাঠের ফসল, গাছের রং আর ফুল, শরতে কাশফুল, কুয়াশা, মেঘ, বৃষ্টি আর ঝড় ঋতুর সাথে বদলায়, বর্ষায় খালের স্রোত একটু বাড়ে। একটাই বাতাস গাছ, ঘাস, ফসল, পানি, নৌকা আর কাপড় সব নাড়ায়। নৌকা পানিতে ভাসে, বৈঠার প্রতিটা টানে এগোয়, চললে দুই পাশে পানি সরে আর পেছনে wake; কচুরিপানা খালের কিনারার স্থির পানিতে জমে, নৌকার মাঝপথ খোলা থাকে, আর খোল বা বৈঠা লাগলে সরে যায়। খালের শেষে বিলে পৌঁছে কুয়াশা নামে, আর যাত্রা আবার শুরু থেকে।
মানুষেরা (মাঝি আর সেতুর মেয়েটি) গেমের চরিত্রের মতো করে গড়া: MakeHuman-এর CC0 শরীর, কঙ্কাল আর ত্বক, চোখ, ভ্রু, পাপড়ি আর চুল (`public/humans/`, ≈১.৩ MB; নিচে "মানুষ")। এগুলো আর মাটি, নুড়ি ও গাছের বাকলের ১২টা ফটো-টেক্সচার (Poly Haven, CC0, ≈৪.৫ MB; নিচে তালিকা) ছাড়া কোনো ছবি, মডেল বা শব্দের ফাইল নেই। পাড়, গাছ, ঘাস, ঘর, নৌকা, কচুরিপানা, কাপড়, বাকি টেক্সচার আর শব্দ সব লোড হওয়ার সময় কোড দিয়ে তৈরি হয়।

## চালানো

এই ফোল্ডারে:

```bash
npm run dev        # http://localhost:5173
npm run build      # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
npm run typecheck
```

এই ফোল্ডারের প্যাকেজগুলো (three, vite, typescript) মূল রিপোর `node_modules` থেকে নেওয়া হয়। আলাদাভাবে চালাতে চাইলে এখানে `npm install` করুন।

ছবির মান: ধীর যন্ত্রে ছবি নিজে থেকেই একটু ছোট হয়ে মসৃণ থাকার চেষ্টা করে; সবচেয়ে ছোট ছবিতেও ৩০ fps-এর নিচে থাকলে কম খুঁটিনাটির স্তরে নামে (দূরের জিনিস কম, প্রতিফলন আর ছায়া কিছুটা মোটা, ঘন ঘাস কাছে)। `?quality=low` বা `?quality=high` দিয়ে খুললে স্তর বেঁধে দেওয়া যায়।

ডিবাগের জন্য `?debug` দিয়ে খুললে `window.__river` পাওয়া যায়। গ্রামের নকশা (নদী, খাল, বিল, বাড়ি, পুকুর, পথ) `src/world/plan.ts`-এ। dev server চালু রেখে `node scripts/headless/shoot.mjs shots` চালালে headless Chrome দিয়ে দৃশ্যের ছবি তোলা যায়। কীভাবে ব্যবহার করবেন আর এই প্রজেক্টের পুরো ইতিহাস `HANDOFF.md`-এ লেখা আছে।

## নিয়ন্ত্রণ

নিচের বারে সব নিয়ন্ত্রণ আছে: সময় চালু/থামানো আর গতি, ২৪ ঘণ্টার টাইমলাইন (তাতে সেদিনের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের চিহ্ন; চিহ্নে চাপলে সেই মুহূর্তে গিয়ে ক্যামেরা সেদিকে ঘোরে), বাংলা তারিখ আর ঋতু, ক্যামেরা মোড (নৌকা, মুক্ত, চলচ্চিত্র), দৃশ্য, চাঁদের কলা, ঋতু, শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো, মানচিত্র আর সাহায্য। আবহাওয়া (শান্ত, হাওয়া, ঝোড়ো হাওয়া, হালকা বৃষ্টি, বৃষ্টি, ঝড়) ঋতু অনুযায়ী নিজে থেকে আসে। মাউস থেমে থাকলে বারটা সরে যায়, নড়লে ফিরে আসে। `?` চাপলে পুরো তালিকা দেখা যায়।

| কী | কাজ |
|---|---|
| টেনে আনা / তীর-চাবি | নৌকার চারপাশে ঘোরা |
| স্ক্রল / পিঞ্চ, `+` `-` | কাছে-দূরে |
| `V`, `R` | পরের দৃশ্য (পেছন, মাঝির পাশ, সামনে, উঁচু), শুরুর দৃশ্যে ফেরা |
| `1` `2` `3` | নৌকার ক্যামেরা, মুক্ত ক্যামেরা, চলচ্চিত্র |
| মুক্ত ক্যামেরায় `W` `A` `S` `D`, `↑` `↓`, `E` `Q`, `Shift` | চলা, ওপরে-নিচে, দ্রুত; টেনে বা `←` `→` দিয়ে ঘোরা (ছোট জগতের ভেতরে, গাছের মাথার একটু ওপর পর্যন্ত) |
| `C` | চলচ্চিত্র: ২১টা দৃশ্যে গ্রামের এক বছর, পাঁচ অংশে: শীতের সকাল (ভোর, মাঝি, গ্রামের ঘাট, গ্রামের পথ, সরিষার মাঠ, লবণ মাঠ, ট্রেন যাচ্ছে), ঋতু বদল (বসন্তের রং, কালবৈশাখী), বর্ষা (বর্ষার খাল, বর্ষার ঘের, ডুবো মাঠে আমন, শাপলা বিল), শরৎ-হেমন্ত (পুকুরপাড়, কাশবন, জেলের জাল, হেমন্তের ধান), সন্ধ্যা আর রাত (সেতুর নিচে, সূর্যাস্ত, চাঁদ ওঠা, রাতের বিল); চলন্ত অবস্থায় মিলিয়ে যাওয়া দৃশ্য-বদল, লেটারবক্স, ক্যাপশন |
| `←` `→` | চলচ্চিত্রে আগের বা পরের দৃশ্য (ওপরের বোতামেও) |
| `Space`, `[` `]` | সময় চালু/থামানো, সময়ের গতি (১×, ৪×, ১৬×, ৬৪×) |
| `T` চেপে ধরা | সময় খুব দ্রুত |
| `N` | পরের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় বা চন্দ্রাস্ত |
| `Y` | পরের ঋতু (মেনু থেকে "আজকের তারিখ"-এ ফেরা যায়) |
| `L` | মানচিত্র: কোথায় যাবেন |
| `M`, `F`, `H`, `?` | শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো, সাহায্য |

ঘড়ি প্রতিটা সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের কাছে ধীর হয়। চাঁদ প্রতিদিন একটু দেরিতে ওঠে আর তার কলা বদলায়। ১২ সেকেন্ড কিছু না ছুঁলে ক্যামেরা নিজে থেকে সেই ঘটনার দিকে ঘোরে, আর ৩০ সেকেন্ড কিছু না ছুঁলে চলচ্চিত্র ট্যুর শুরু হয়। টানলে বা স্ক্রল করলে ক্যামেরা আবার আপনার হাতে ফিরে আসে, আপনার সময় আর ঋতুসহ।

ঋতু বা চাঁদের কলা বাছলে জগৎ হঠাৎ বদলায় না: বছর কয়েক সেকেন্ডে সেই ঋতুর দিকে ঘোরে (ফসল গজায়, পাকে, নদীর পানি ওঠে-নামে), চাঁদ ধীরে বাড়ে-কমে, বৃষ্টি আর বাতাস নিজের গতিতে আসে। প্রতিটা বাছাই এক মিনিট থাকে, তারপর জগৎ মসৃণভাবে আজকের ঋতু, ঋতুর আবহাওয়া আর আসল চাঁদে ফেরে।

## গঠন

| ফোল্ডার | কী আছে |
|---|---|
| `src/core/` | শেয়ার করা uniform (সময়, সূর্য, কুয়াশা, বাতাস, পানির উচ্চতা, ঋতু), noise, seeded RNG |
| `src/render/` | পোস্ট পাইপলাইন (প্রতিফলন → HDR দৃশ্য → bloom → আলোর রশ্মি → grade), material patch (মাটির ফটো-স্তর, পানির নিচের রং), ক্যানভাসে আঁকা টেক্সচার, ফটো-টেক্সচার লোড, instancing |
| `src/world/` | গ্রামের নকশা (`plan.ts`), নদী-খাল-বিল আর নৌকার পথ (`waterways.ts`), মাটি (ভিটা, পুকুর আর তার পাড়, নদীর বাঁধ আর চর, পাড়ের ঢাল), রাস্তা আর পথ, সেতু আর সাঁকো, terrain, পানি, আকাশ, গাছপালা, কাশবন, ক্যামেরার চারপাশের ঘন ঘাস আর বুনোফুল, মাঠের ফসল, কিনারায় ভাসা কচুরিপানা (নিজস্ব physics), পুকুরের শাপলা, শাপলা বিল (নৌকা ঠেলে সরানো শাপলা, পদ্ম, নলখাগড়া, বক), বাড়ি (উঠান ঘিরে ঘর, রান্নাঘর, গোয়াল, খড়ের গাদা, ঘাট, ঘাটে বাঁধা নৌকা), নৌকা আর তার physics (ভাসা, বৈঠা বাওয়া, ভারসাম্য), মানুষ (MakeHuman-এর শরীর কঙ্কালে, dual quaternion skinning; মাঝির বৈঠায় মুঠো করা হাত, বাতাসে নড়া লুঙ্গি আর গামছা, গায়ে বসানো স্যান্ডো; সেতুর মেয়েটির কামিজ, সালোয়ার, ওড়না আর দোলা বেণী), বৃষ্টি, ঢেউ, পাখি ও জোনাকি |
| `src/env/` | সূর্য আর চাঁদের অবস্থান ও কলা, ঘটনার কাছে ধীর হওয়া ঘড়ি, প্রতিটি সময়ের রং আর আলো, ষড়ঋতু আর বাংলা তারিখ, আবহাওয়া, বাতাস |
| `src/rig/` | নৌকার যাত্রা (নদী ধরে, মোহনায় খালে ঢুকে বিল পর্যন্ত, তারপর কুয়াশা পেরিয়ে আবার শুরু), নৌকা অনুসরণকারী ক্যামেরা (পানির ওপরে থাকে, সেতুর খিলানের নিচে নামে), মুক্ত ক্যামেরা আর চলচ্চিত্র ট্যুরের পরিচালক |
| `src/ui/` | লোডার, নিয়ন্ত্রণের বার, টাইমলাইন, সাহায্যের তালিকা আর তথ্যসূত্র, বাংলা সময় আর তিথি |
| `src/audio/` | Web Audio দিয়ে তৈরি শব্দ: নদী আর খালের পানি, বাতাস, বৈঠা, পাখি, ঝিঁঝিঁ, বৃষ্টি, বজ্র |

## মানুষ

মানুষেরা গেমের চরিত্রের মতো করে তৈরি: একটা আসল অনুপাতের শরীরের মেশ, তার ভেতরে কঙ্কাল, প্রতিটা vertex কোন হাড়ের সাথে কতটা নড়বে তার ওজন (skin weights), ফটো থেকে তৈরি ত্বক, আলাদা চোখ, ভ্রু, পাপড়ি আর চুলের কার্ড। সবকিছুর উৎস [MakeHuman](https://www.makehumancommunity.org) (CC0, ২০২০ থেকে)। `scripts/humans/`:

```bash
node scripts/humans/fetch.mjs     # MakeHuman-এর উপাত্ত scripts/humans/cache/-এ (asset pack থেকে শুধু দরকারি ফাইল)
node scripts/humans/build.mjs     # চরিত্রগুলো গড়ে public/humans/humans.json আর humans.bin লেখে
python scripts/humans/textures.py # ত্বক, চুল, চোখ, ভ্রু আর পাপড়ির WebP (Python 3 আর Pillow লাগে)
```

`scripts/humans/config.mjs`-এ দুটো চরিত্র: মাঝি (চল্লিশের কোঠায়, রোদে পোড়া) আর সেতুর মেয়েটি। MakeHuman-এর macro (লিঙ্গ, বয়স, পেশি, ওজন, উচ্চতা আর তিন জাতিগত আকারের মিশ্রণ) দিয়ে শরীরের গড়ন, তারপর নির্দিষ্ট উচ্চতায় মাপা। ত্বক MakeHuman-এর একটা হালকা আর একটা গাঢ় ত্বকের মিশ্রণ, শ্যামলা রঙের দিকে আনা; পুরুষদের মুখে দাড়ির ছায়া আর গোঁফ। চলার সময় শরীর তার হাড় ধরে নড়ে (dual quaternion skinning, যাতে কাঁধ আর কব্জি মোচড়ালেও আকার ঠিক থাকে); হাত যা ধরে তার চারপাশে আঙুল মুঠো হয়, চোখ তাকায় আর পলক পড়ে। গায়ে লাগানো কাপড় (স্যান্ডো, কামিজের ওপরের অংশ, সালোয়ার) শরীরের ওপরে আলাদা খোল, তার নিচের চামড়া আঁকা হয় না; ঢিলা কাপড় (লুঙ্গি, গামছা, কামিজের নিচের অংশ, ওড়না) আগের মতো বাতাসে নড়া কাপড়। কোনো আসল মানুষের চেহারা নয়।
