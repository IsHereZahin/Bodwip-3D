# বদ্বীপ 3D (Bodwip 3D)

বাংলার এক গ্রামের ছোট নদী দিয়ে মাঝির নৌকায় ছয় ঋতুর যাত্রা, ব্রাউজারে রিয়েল-টাইম 3D। গ্রাম, গাছ, পানি, আকাশ, নৌকা আর শব্দ সব কোডে তৈরি (three.js, Vite, TypeScript)।

## চালানো

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/-এ প্রোডাকশন বিল্ড
npm run typecheck
```

build-এর সময় সাইটের ঠিকানা দিলে canonical লিংক, শেয়ারের ছবি আর `sitemap.xml` ঠিক ঠিকানায় বসে (`.env`-এ বা কমান্ডে):

```bash
SITE_URL=https://example.org/ npm run build
```

Vercel-এ রাখলে Vercel Web Analytics ভিজিট গোনে (প্রজেক্টের সেটিংসে Analytics চালু করতে হয়)। ধীর যন্ত্রে ছবির মান নিজে থেকে কমে; `?quality=low` বা `?quality=high` দিয়ে বেঁধে দেওয়া যায়।

## নিয়ন্ত্রণ

নিচের বারে সময়, ঋতু, লাইভ, ক্যামেরা, চাঁদ, শব্দ আর মানচিত্র। `?` চাপলে সব চাবির তালিকা।

| কী | কাজ |
| --- | --- |
| টেনে আনা, স্ক্রল | চারপাশে ঘোরা, কাছে-দূরে |
| `1` `2` `3` | নৌকার ক্যামেরা, মুক্ত ক্যামেরা, চলচ্চিত্র |
| `C` | চলচ্চিত্র: গ্রামের এক বছর |
| `Space`, `[` `]` | সময় চালু/থামানো, সময়ের গতি |
| `0` | লাইভ: বাংলাদেশের এই মুহূর্ত |
| `L` | মানচিত্র |
| `M`, `F`, `H` | শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো |

## উপাদান ও লাইসেন্স

- চলচ্চিত্রের প্রথম ধারণা [koi-pond-garden](https://github.com/souranyp-stack/koi-pond-garden) (MIT) থেকে অনুপ্রাণিত; কোড নিজস্ব।
