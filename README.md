# নদী — সোনালি বিকেলে মহেশখালীর পথে

রিয়েল-টাইম 3D দৃশ্য: মহেশখালী চ্যানেল দিয়ে মাঝি বৈঠা বেয়ে ডিঙি নিয়ে দক্ষিণে সাগরের দিকে চলে। জগৎটা আসল মহেশখালীর মানচিত্র মেনে, দৈর্ঘ্যে প্রায় পাঁচ ভাগের এক ভাগ ছোট করে গড়া। ডান পাড়ে মহেশখালী দ্বীপ: পূর্ব উপকূল বরাবর বনে ঢাকা পাহাড়ের সারি, গোরকঘাটার জেটি আর বাজার, তার ওপরে টিলার চূড়ায় আদিনাথ মন্দির আর সেখানে ওঠার সিঁড়ি, রাখাইন প্যাগোডা, পাহাড়ের ঢালে পানের বরজ; পাহাড়ের পশ্চিমে নিচু জমিতে ধানক্ষেত, কোহেলিয়া নদী আর লবণ মাঠ, বঙ্গোপসাগরের সৈকতে ঝাউবন, মুখের দিকে ম্যানগ্রোভ; দক্ষিণে খালের ওপারে বালিয়াড়ি আর শুঁটকির মাচার সোনাদিয়া। বাম পাড়ে মূল ভূখণ্ড, দূরে পাহাড়, মুখে কক্সবাজার। নদী কোথাও চওড়া আর অগভীর, কোথাও সরু আর গভীর; পাশ থেকে খাল বেরিয়ে গেছে, পথে নৌকা একটা পুরোনো ইটের সেতুর নিচ দিয়ে (তার ওপরে লাল ছাতা হাতে একটি মেয়ে দাঁড়িয়ে নদী দেখে) খাল ধরে একটা শাপলা বিল পার হয়, আর শেষে নদী চওড়া হয়ে উপকূলের লবণ মাঠের পাশ দিয়ে মোহনায় যায়। দুই পাড়ে গ্রাম, নারকেল-সুপারি গাছ, ধানক্ষেত, মাঠের ভেতরে ছোট জলাভূমি, চরে কাশবন। পাড়ে আর নদীতে জেলেরা ভেসাল জাল তোলে-নামায়।
দৃশ্য খোলে সেদিনের সূর্যাস্তের একটু আগে, সোনালি আলোয়। দিন থেকে রাত পর্যন্ত পুরো চক্র চলে, আর আজকের তারিখ থেকে ছয় ঋতু: নদীর পানি ওঠে-নামে, মাঠের ফসল, গাছের রং আর ফুল, কুয়াশা, মেঘ, বৃষ্টি আর ঝড় ঋতুর সাথে বদলায়। একটাই বাতাস গাছ, ঘাস, ফসল, পানি, নৌকা, জাল আর কাপড় সব নাড়ায়। বাতাস যত জোরে, নদীর ঢেউ তত বড় আর লম্বা; নৌকা ঢেউয়ে ওঠে-নামে, দোলে, মাঝি শক্ত হয়ে দাঁড়ায়। নৌকা মাল নিয়ে পানিতে গভীরে বসে, চললে দুই পাশে পানি সরে, পেছনে wake; বৈঠার প্রতিটা টানে নৌকা এগিয়ে যায়, জোরালো টানে আরও। নদী দক্ষিণে সাগরের দিকে বয়, তাই সূর্য আর চাঁদ বামে ওঠে, ডানে অস্ত যায়, সামনে চোখে পড়ে না।
ধানক্ষেতে আসল ধান সারি করে দাঁড়ানো (চারা, সবুজ, পাকা সোনালি, নাড়া), শীতে হলুদ ফুলে ভরা সরিষা; উপকূলে লবণের খোলা: থিতানোর পুকুর, বাষ্পীভবন মাঠ, কালো পলিথিনে লবণ জমার মাঠ, মাটির আইল, স্তূপ আর গোলাঘর।
মাটি, নুড়ি আর গাছের বাকলের ১২টা ফটো-টেক্সচার (Poly Haven, CC0, ≈৪.৫ MB; নিচে তালিকা) ছাড়া কোনো ছবি, মডেল বা শব্দের ফাইল নেই। পাড়, গাছ, ঘাস, ঘর, নৌকা, কচুরিপানা, বাকি টেক্সচার আর শব্দ সব লোড হওয়ার সময় কোড দিয়ে তৈরি হয়।

## চালানো

এই ফোল্ডারে:

```bash
npm run dev        # http://localhost:5173
npm run build      # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
npm run typecheck
```

এই ফোল্ডারের প্যাকেজগুলো (three, vite, typescript) মূল রিপোর `node_modules` থেকে নেওয়া হয়। আলাদাভাবে চালাতে চাইলে এখানে `npm install` করুন।

ডিবাগের জন্য `?debug` দিয়ে খুললে `window.__river` পাওয়া যায়। dev server চালু রেখে `node scripts/headless/shoot.mjs shots` চালালে headless Chrome দিয়ে দৃশ্যের ছবি তোলা যায়। কীভাবে ব্যবহার করবেন আর এই প্রজেক্টের পুরো ইতিহাস `HANDOFF.md`-এ লেখা আছে।

## নিয়ন্ত্রণ

নিচের বারে সব নিয়ন্ত্রণ আছে: সময় চালু/থামানো আর গতি, ২৪ ঘণ্টার টাইমলাইন (তাতে সেদিনের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের চিহ্ন; চিহ্নে চাপলে সেই মুহূর্তে গিয়ে ক্যামেরা সেদিকে ঘোরে), বাংলা তারিখ আর ঋতু, ক্যামেরা মোড, দৃশ্য, চাঁদের কলা, ঋতু, আবহাওয়া, শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো আর সাহায্য। মাউস থেমে থাকলে বারটা সরে যায়, নড়লে ফিরে আসে। `?` চাপলে পুরো তালিকা দেখা যায়।

| কী | কাজ |
|---|---|
| টেনে আনা / তীর-চাবি | নৌকার চারপাশে ঘোরা |
| স্ক্রল / পিঞ্চ, `+` `-` | কাছে-দূরে |
| `V`, `R` | পরের দৃশ্য (পেছন, মাঝির পাশ, সামনে, উঁচু), শুরুর দৃশ্যে ফেরা |
| `1` `2` `3` | নৌকার ক্যামেরা, মুক্ত ক্যামেরা, চলচ্চিত্র |
| মুক্ত ক্যামেরায় `W` `A` `S` `D`, `↑` `↓`, `E` `Q`, `Shift` | চলা, ওপরে-নিচে, দ্রুত; টেনে বা `←` `→` দিয়ে ঘোরা |
| `C` | চলচ্চিত্র ট্যুর: ≈৫.৩ মিনিটে এক বছর আর এক দিন (ভোর থেকে রাত, শীত থেকে শীত), নদী, খাল, পুরোনো সেতু, বিল, মাঠ, গ্রাম, জেলে, আদিনাথ পাহাড়, লবণ মাঠ, সোনাদিয়া, ঝড়, বৃষ্টি, সূর্যাস্ত, চাঁদ ওঠা; dissolve, লেটারবক্স, ক্যাপশন |
| `Space`, `[` `]` | সময় চালু/থামানো, সময়ের গতি (১×, ৪×, ১৬×, ৬৪×) |
| `T` চেপে ধরা | সময় খুব দ্রুত |
| `N` | পরের সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় বা চন্দ্রাস্ত |
| `Y` | পরের ঋতু (মেনু থেকে "আজকের তারিখ"-এ ফেরা যায়) |
| `B` | আবহাওয়া: ঋতু অনুযায়ী, পরিষ্কার, মৃদু হাওয়া, জোর হাওয়া, হালকা বৃষ্টি, বৃষ্টি, ঝড় |
| `M`, `F`, `H`, `?` | শব্দ, পূর্ণ পর্দা, নিয়ন্ত্রণ লুকানো, সাহায্য |

ঘড়ি প্রতিটা সূর্যোদয়, সূর্যাস্ত, চন্দ্রোদয় আর চন্দ্রাস্তের কাছে ধীর হয়। চাঁদ প্রতিদিন একটু দেরিতে ওঠে আর তার কলা বদলায়। ১২ সেকেন্ড কিছু না ছুঁলে ক্যামেরা নিজে থেকে সেই ঘটনার দিকে ঘোরে, আর ৩০ সেকেন্ড কিছু না ছুঁলে চলচ্চিত্র ট্যুর শুরু হয়। টানলে বা স্ক্রল করলে ক্যামেরা আবার আপনার হাতে ফিরে আসে, আপনার সময় আর ঋতুসহ।

ঋতু, আবহাওয়া বা চাঁদের কলা বাছলে জগৎ হঠাৎ বদলায় না: বছর কয়েক সেকেন্ডে সেই ঋতুর দিকে ঘোরে (ফসল গজায়, পাকে, নদীর পানি ওঠে-নামে), চাঁদ ধীরে বাড়ে-কমে, বৃষ্টি আর বাতাস নিজের গতিতে আসে। প্রতিটা বাছাই এক মিনিট থাকে, তারপর জগৎ মসৃণভাবে আজকের ঋতু, ঋতুর আবহাওয়া আর আসল চাঁদে ফেরে।

## গঠন

| ফোল্ডার | কী আছে |
|---|---|
| `src/core/` | শেয়ার করা uniform (সময়, সূর্য, কুয়াশা, বাতাস, পানির উচ্চতা, ঋতু), noise, seeded RNG |
| `src/render/` | পোস্ট পাইপলাইন (প্রতিফলন → HDR দৃশ্য → bloom → আলোর রশ্মি → grade), material patch (মাটির ফটো-স্তর, পানির নিচের রং), ক্যানভাসে আঁকা টেক্সচার, ফটো-টেক্সচার লোড, instancing |
| `src/world/` | ভূগোল (চ্যানেল, চর, গ্রাম, মহেশখালী দ্বীপ, পাহাড়, কোহেলিয়া, সোনাদিয়া), মহেশখালীর স্থাপনা (মন্দির, জেটি, বাজার, প্যাগোডা, পানের বরজ, শুঁটকি, কক্সবাজার), terrain, পানি, আকাশ, গাছপালা, ক্যামেরার চারপাশের ঘন ঘাস আর বুনোফুল, স্রোতে ভাসা কচুরিপানা (নিজস্ব physics), পুকুরের শাপলা, খাল, শাপলা বিল (নৌকা ঠেলে সরানো শাপলা, পদ্ম, নলখাগড়া, বক), গ্রাম, নৌকা আর তার physics (ভাসা, বৈঠা বাওয়া, ভারসাম্য), মাঝি (বৈঠায় মুঠো করা হাত, বাতাসে নড়া লুঙ্গি, গেঞ্জি আর গামছা), ভেসাল জাল আর জেলে (লিভারের physics, কাপড়ের মতো জাল, হাতে-হাতে দড়ি টানা, নোঙর করা মাছধরা নৌকা), উপকূলের লবণ মাঠ, ছোট জলাভূমি, বৃষ্টি, ঢেউ, পাখি ও জোনাকি |
| `src/env/` | সূর্য আর চাঁদের অবস্থান ও কলা, ঘটনার কাছে ধীর হওয়া ঘড়ি, প্রতিটি সময়ের রং আর আলো, ষড়ঋতু আর বাংলা তারিখ, আবহাওয়া, বাতাস |
| `src/rig/` | নৌকা অনুসরণকারী ক্যামেরা, মুক্ত ক্যামেরা আর চলচ্চিত্র ট্যুরের পরিচালক |
| `src/ui/` | লোডার, নিয়ন্ত্রণের বার, টাইমলাইন, সাহায্যের তালিকা, বাংলা সময় আর তিথি |
| `src/audio/` | Web Audio দিয়ে তৈরি শব্দ: নদী, বাতাস, দাঁড়, পাখি, ঝিঁঝিঁ, বৃষ্টি, বজ্র |

## টেক্সচার

`public/textures/`-এ [Poly Haven](https://polyhaven.com)-এর ছয়টা টেক্সচার, প্রতিটার রং আর normal map (1K, WebP-তে রূপান্তরিত)। সবগুলো CC0, অর্থাৎ যেকোনো কাজে বিনা শর্তে ব্যবহার করা যায়।

| ফাইল | Poly Haven-এ | কোথায় |
|---|---|---|
| `grass_*` | forrest_ground_01 | পাড়ের ওপরের ঘাসজমি |
| `dirt_*` | brown_mud_dry | গ্রামের উঠান, শুকনো জায়গা |
| `mud_*` | brown_mud_03 | পাড়ের ঢাল, নদীর তলা |
| `sand_*` | sand_02 | চর |
| `pebbles_*` | ganges_river_pebbles | জলরেখার নুড়ি |
| `bark_*` | bark_willow | আম, রেইন ট্রি আর দূরের গাছের গুঁড়ি |

টেক্সচার না পাওয়া গেলে (যেমন অফলাইনে) দৃশ্য আগের আঁকা রঙেই চলে।

চলচ্চিত্র ট্যুরের প্রথম ধারণা (শট-তালিকা, কাট, লেটারবক্স, ক্যাপশন) [koi-pond-garden](https://github.com/souranyp-stack/koi-pond-garden) (MIT) থেকে অনুপ্রাণিত। কোড নিজস্ব।
